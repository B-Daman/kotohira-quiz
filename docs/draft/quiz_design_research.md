# 択一クイズ（4択）設計リサーチ

作成日: 2026-04-06

本ドキュメントは、教育学・クイズ設計の知見に基づき、4択クイズの設計指針をまとめたものである。
琴平クイズの品質向上を目的とし、出題パターン・問題品質・ご当地クイズ設計・バランスの4つの観点で整理する。

---

## 1. 択一クイズの出題パターン分類

### 1.1 問題形式の分類（Question Type Taxonomy）

Glessmer (2014) の分類およびCBT-Solutionsの分類を統合すると、以下のパターンが識別できる。

| # | パターン名 | 説明 | 認知レベル | 例 |
|---|-----------|------|-----------|-----|
| 1 | **事実想起（Recall）** | 単純な事実の想起 | 記憶 | 「金刀比羅宮の本宮までの石段は何段？」 |
| 2 | **定義・説明（Definition）** | 用語や概念の正しい定義を選ぶ | 記憶〜理解 | 「五人百姓とは何か？」 |
| 3 | **分類（Classification）** | あるものがどのカテゴリに属するか判断 | 理解 | 「旭社の祭神は次のうちどれか？」 |
| 4 | **概念説明（Explanation）** | 複数の説明文から最適なものを選ぶ | 理解 | 「金毘羅信仰が海上安全と結びついた理由として最も適切なのは？」 |
| 5 | **比較（Comparison）** | 2つ以上の要素の相違・共通点を問う | 分析 | 「本宮と奥社の祭神の違いとして正しいのは？」 |
| 6 | **因果・理由（Cause/Reason）** | なぜそうなったかの理由を問う | 分析 | 「神仏分離令で松尾寺が廃寺になった理由は？」 |
| 7 | **応用（Application）** | 学んだ知識を新しい状況に適用 | 応用 | 「参拝に2時間取れる場合、奥社まで行って帰れるか？」 |
| 8 | **手順（Procedural）** | 正しい手順・順序を問う | 応用 | 「参道を上る際に最初に通る建造物は？」 |
| 9 | **最善判断（Best Answer）** | 複数の妥当な選択肢から最適を選ぶ | 評価 | 「金刀比羅宮の文化財として最も重要な特徴は？」 |
| 10 | **予測（Prediction）** | 結果や展開を予測させる | 分析〜評価 | 「令和の大改修後、旭社はどのような姿になると考えられるか？」 |

### 1.2 ブルーム・タキソノミーとの対応

改訂版ブルーム・タキソノミー（Anderson & Krathwohl, 2001）の6段階と、4択問題の適性を整理する。

| 認知レベル | 定義 | 4択への適性 | 問い方の例 |
|-----------|------|------------|-----------|
| **記憶（Remember）** | 事実・用語の想起 | 最適 | 「〜は何か？」「〜はどれか？」 |
| **理解（Understand）** | 意味の解釈・要約 | 最適 | 「〜を最もよく説明しているのは？」「〜の意味は？」 |
| **応用（Apply）** | 知識の新場面への適用 | 適 | 「〜の場合、どうすべきか？」「〜を使って解決するには？」 |
| **分析（Analyze）** | 構成要素への分解・関係の把握 | 適 | 「〜の原因は？」「〜と〜の関係は？」 |
| **評価（Evaluate）** | 基準に基づく判断 | やや困難 | 「最も適切なのは？」「最も重要な〜は？」 |
| **創造（Create）** | 新しいものの生成 | 不適 | 4択では測定困難。記述式向き |

**実践的ポイント**: eLearning Industry の指摘によれば、4択問題に最適なのは「記憶・理解・応用・分析」の4レベルである。「評価」は「最も適切な〜」形式で対応可能だが、「創造」は4択では本質的に測定できない。

## 2. 良い択一問題の条件

### 2.1 良問の特徴（10の原則）

PMC掲載のエビデンスに基づく論文 (Dickinson & Franzone, 2023) および University of Waterloo のガイドラインを統合する。

#### ステム（問題文）の原則

1. **問題文だけで完結させる**: 選択肢を見なくても解答の方向性がわかるように書く
2. **簡潔に書く**: 認知負荷理論に基づき、不要な情報を排除する
3. **肯定形で書く**: 否定形（「〜でないものは？」）は認知負荷が高く避ける。やむを得ない場合は太字・大文字で強調
4. **一問一概念**: 1つの問題で1つの知識・概念のみを問う
5. **授業/学習で使った用語に揃える**: 不慣れな言い回しは知識ではなく読解力をテストしてしまう

#### 選択肢の原則

6. **選択肢の長さを揃える**: 正解だけ長い（または短い）と手がかりになる
7. **文法的に統一する**: すべての選択肢がステムと文法的に整合するようにする
8. **論理的な順序で並べる**: 数値なら昇順、時系列なら年代順
9. **正解の位置を均等に分散**: a/b/c/d にほぼ等確率で配置する
10. **「正解」ではなく「最も適切な答え」と指示する**: 微妙な判断を含む問題に対応できる

### 2.2 避けるべきアンチパターン

| アンチパターン | 問題点 | 改善策 |
|--------------|--------|--------|
| **「すべて正しい」選択肢** | 2つ正しいと分かれば残りを検討せず正解できる | 使用しない |
| **「正しいものはない」選択肢** | 誤答排除しか測定できず、正しい知識を測れない | 使用しない |
| **引っかけ問題** | 知識ではなく注意力をテストしてしまう | 素直な問い方にする |
| **絶対語（always/never/必ず/絶対に）** | テスト慣れした人が即座に排除できる | 相対的な表現を使う |
| **選択肢の重複・包含関係** | 論理的に正解が特定できてしまう | 相互排他的にする |
| **正解だけ明らかに詳しい** | 正解が目立ち、知識なしで選べる | 同程度の詳細さにする |
| **文法的な不整合** | 「aで始まる選択肢にanが来る」等で正解がバレる | ステムと全選択肢を通して確認 |
| **否定の二重使用** | 「〜でないものを選べ」＋「〜ではない」は理解困難 | 肯定形に書き換える |

### 2.3 ディストラクター（不正解選択肢）の設計

PMC論文 (Gierl et al., 2017) に基づくディストラクター設計の体系的手法:

#### 良いディストラクターの3条件

1. **もっともらしい（Plausible）**: 知識がない人が「正解かも」と思える内容
2. **よくある誤解に基づく（Misconception-based）**: 学習者が実際に陥りやすい間違いを反映
3. **同質的（Homogeneous）**: 正解と同じカテゴリの内容（正解が人名なら他も人名）

#### ディストラクター生成の具体的手法

| 手法 | 説明 | 琴平クイズでの例 |
|-----|------|----------------|
| **よくある間違い** | 学習者が頻繁に混同するもの | 石段数785段に対し「1368段」（奥社まで）|
| **隣接情報** | 正解と同カテゴリの関連情報 | 祭神を問う際、他の社殿の祭神を並べる |
| **部分的に正しい** | 一部は合っているが全体として不正確 | 「大物主神と菅原道真」のように片方だけ正しい |
| **時代の混同** | 異なる時代の情報を混ぜる | 建立年を問う際、近接する年代を並べる |
| **規模の混同** | 数値のスケールを変える | 「約500段」「約1000段」「約1200段」 |

#### ディストラクターの選択肢数

研究知見: PMC論文およびFACS (American College of Surgeons) のガイドラインによれば、**3択（正解1＋誤答2）が最適**とする研究結果がある。4択との識別力の差は最小限で、問題作成コストが大幅に削減できる。

ただし、CBT-Solutionsの分析によれば、日本の検定試験では**4択が標準**であり、統計的な比較可能性の観点から4択を推奨している。運による正答率は4択で25%、5択で20%であり、開発コスト対効果で4択が最適バランスとなる。

**琴平クイズへの適用**: 4択を維持する。ただし質の低いディストラクターを無理に作るくらいなら、3つの選択肢のほうが良問になる。

### 2.4 難易度の調整方法

| 調整手法 | 易化 | 難化 |
|---------|------|------|
| **ディストラクターの類似度** | 正解と明確に異なる選択肢 | 正解と紛らわしい選択肢 |
| **問われる知識の深さ** | 有名な事実 | 細部・専門的知識 |
| **認知レベル** | 記憶・理解 | 分析・評価 |
| **文脈の有無** | 直接的な問い | 状況設定付きの問い |
| **選択肢の表現** | はっきり異なる表現 | 微妙に異なる表現 |

難易度指標（Difficulty Index）: 正答率で測定する。
- Easy: 正答率 70%以上
- Medium: 正答率 40〜70%
- Hard: 正答率 40%未満

識別力指標（Discrimination Index）: 上位群と下位群の正答率差で測定する。0.3以上が望ましい。

## 3. ご当地クイズ・地域学習クイズの設計

### 3.1 ご当地検定の全体像

日本では2003年の「博多っ子検定」を皮切りに、全国で数百のご当地検定が実施されてきた (Wikipedia)。
主催は商工会議所、観光協会、自治体が中心で、目的は「地域人材の育成」「地域の魅力発信」の2軸に大別される。

#### 代表的なご当地検定の構造

**京都検定（京都・観光文化検定試験）の例**:
- 3級: 4択マークシート100問、合格ライン70%、公式テキストから90%以上出題
- 2級: 4択マークシート100問、合格ライン70%、公式テキストから70%以上出題
- 1級: 記述式・小論文、合格ライン80%
- 出題カテゴリ: 歴史、史跡、神社、寺院、建築、庭園、美術、伝統工芸、伝統文化、花街、祭と行事、京料理、京菓子、ならわし、ことばと伝説、地名、自然、観光

### 3.2 ご当地クイズの出題カテゴリ体系

ご当地検定の出題範囲を分析すると、以下のカテゴリ体系が浮かび上がる。

| 大カテゴリ | 中カテゴリ例 | 問いやすさ |
|-----------|------------|----------|
| **歴史** | 通史、人物、出来事、年代、文献 | 高 |
| **宗教・信仰** | 祭神、由緒、祭礼、参拝作法 | 高 |
| **建築・美術** | 社殿、文化財、美術品、庭園 | 高 |
| **地理・自然** | 地形、動植物、気候、景観 | 中 |
| **産業・経済** | 名産品、伝統産業、商業史 | 中 |
| **生活・文化** | 食文化、祭り、年中行事、方言 | 高 |
| **文学・芸能** | 文学作品、芸能、映画・ドラマ | 中 |
| **交通・観光** | アクセス、観光施設、まちあるき | 中 |
| **人物** | 歴史上の人物、ゆかりの人物 | 高 |
| **時事・現代** | 最近のイベント、まちづくり | 低（陳腐化リスク） |

### 3.3 「へぇ」と思わせる問題（トリビア要素）の重要性

QuizWitz (2026) の記事が紹介する心理学的知見:

#### 情報ギャップ理論（Loewenstein）
心理学者ジョージ・ローウェンシュタインの「情報ギャップ理論」によれば、知識の空白に気づくと、それを埋めたいという欲求（好奇心）が生じる。クイズの問題文はこの情報ギャップを意図的に作り出し、答えが明かされた瞬間に好奇心が満たされ、小さな快感が生まれる。

#### 「ゴルディロックス・ゾーン」
トリビア問題は心理学でいう「ゴルディロックス・ゾーン」（難しすぎず、易しすぎず、ちょうどいい）に位置するとき、最大の快感をもたらす。

#### 脳科学的メカニズム
「Aha!」の瞬間には、前帯状皮質（葛藤検出）、前頭前皮質（問題解決）、海馬（記憶）が同時に活性化し、ドーパミンが放出される。この報酬系の反応が「もっと知りたい」というモチベーションを生む。

#### テスティング効果
「テスティング効果（testing effect）」: 能動的に情報を検索する行為は、受動的な学習よりもはるかに記憶の定着を促進する。クイズに答えること自体が効果的な学習手段となる。

### 3.4 知的好奇心を刺激する問題の作り方

| 手法 | 説明 | 例 |
|-----|------|-----|
| **意外性のある事実** | 「まさか」と思う事実を問いにする | 「金刀比羅宮は2020年に神社本庁から離脱した。その理由は？」 |
| **数字の驚き** | 規模感を実感させる数字 | 「江戸時代、年間の金毘羅参りの参拝者数は推定何人？」 |
| **つながりの発見** | 一見無関係なものの関連を問う | 「森の石松が金毘羅代参した落語の演目名は？」 |
| **身近な謎解き** | 日常で見かけるものの由来 | 「大門内で飴を売る五人百姓の特権はいつから？」 |
| **比較の面白さ** | 他と比べて特殊な点を問う | 「金刀比羅宮が他の有名神社と異なる珍しい特徴は？」 |
| **解説で「へぇ」** | 問題自体より解説にトリビアを仕込む | 正解発表後に豆知識を付加する |

## 4. 問題のバランス設計

### 4.1 テーマ別バランス

京都検定の出題分析と、topic_taxonomy.md のカテゴリを踏まえた推奨比率:

| カテゴリ | 推奨比率 | 理由 |
|---------|---------|------|
| 金刀比羅宮（祭神・由緒・建築・美術） | 30〜35% | コンテンツの中核。知識の幅が広い |
| 金刀比羅宮（参拝・石段・行事） | 15〜20% | 体験に直結し、訪問者の関心が高い |
| 琴平の歴史・人物 | 10〜15% | 地域の深みを出す |
| 門前町・街道・観光 | 10〜15% | まち歩きの楽しさに直結 |
| 食文化・名産品 | 5〜10% | 親しみやすいテーマ |
| 自然・地理 | 5〜10% | 象頭山・讃岐平野等 |
| 文学・芸能・文化 | 5〜10% | こんぴら歌舞伎等 |
| その他（時事・雑学） | 5%以下 | 陳腐化リスクがあるため少量に |

### 4.2 難易度別バランス

教育学の知見と ScienceDirect 掲載論文 (Weinberg et al., 2022) の推奨:

| 難易度 | 正答率目安 | 推奨比率 | 配置 |
|-------|-----------|---------|------|
| **Easy** | 70%以上 | 30〜40% | 序盤に多く配置し、自信をつける |
| **Medium** | 40〜70% | 40〜50% | 中盤の中心。学習効果が最も高い |
| **Hard** | 40%未満 | 10〜20% | 終盤やアクセント。達成感を演出 |

**配置の原則**: 易→難の順序が最も効果的。これにより離脱率が最低になり、正答数も最大化される (Weinberg et al., 2022)。

### 4.3 出題パターン別バランス

| パターン | 推奨比率 | 理由 |
|---------|---------|------|
| 事実想起（何？誰？いつ？どこ？） | 40〜50% | 基盤的知識。作問しやすく回答しやすい |
| 定義・説明 | 10〜15% | 用語理解の確認 |
| 因果・理由（なぜ？） | 10〜15% | 深い理解を促す。「へぇ」感が高い |
| 比較・分類 | 5〜10% | 知識の構造化を促す |
| 応用・判断 | 5〜10% | 実用的知識の確認 |
| 手順・順序 | 5〜10% | 参拝順路等、体験に直結 |

### 4.4 問題数の適正規模

#### 1回のクイズセッション

| 目的 | 推奨問題数 | 所要時間目安 |
|-----|-----------|------------|
| カジュアル体験（観光客向け） | 10〜15問 | 5〜10分 |
| しっかり学習（リピーター向け） | 20〜30問 | 15〜20分 |
| 検定試験レベル | 50〜100問 | 30〜60分 |

#### 問題プール全体

Growth Engineering のガイドラインおよびご当地検定の事例から:

- **最低限**: 出題問題数の3〜5倍のプールが望ましい（ランダム出題のため）
- **理想**: テーマごとに十分な問題数を確保し、偏りなく出題できるようにする
- **更新**: 年に1〜2回、新問追加と陳腐化問題の非活性化を行う

琴平クイズの現状（約684問）は、カジュアル体験向けの豊富なプールとして十分な規模である。

### 4.5 認知レベル別バランス

| レベル | 推奨比率 |
|-------|---------|
| 記憶 | 30〜40% |
| 理解 | 25〜35% |
| 応用 | 10〜20% |
| 分析 | 10〜15% |
| 評価 | 5%以下 |

## 5. 実践チェックリスト（問題品質レビュー用）

### ステム（問題文）

- [ ] 問題文だけで何を問うているか明確か
- [ ] 不要な情報を含んでいないか
- [ ] 否定形を使っていないか（使う場合は強調しているか）
- [ ] 一問一概念になっているか

### 選択肢

- [ ] 選択肢の長さはほぼ均等か
- [ ] 文法的にステムと整合しているか
- [ ] 「すべて正しい」「正しいものはない」を使っていないか
- [ ] 「必ず」「絶対」「常に」等の絶対語を使っていないか
- [ ] 選択肢同士に包含関係がないか
- [ ] 論理的な順序（数値順・時系列等）で並んでいるか

### ディストラクター

- [ ] すべてのディストラクターがもっともらしいか
- [ ] よくある誤解・混同に基づいているか
- [ ] 正解と同じカテゴリか（人名なら全て人名、数字なら全て数字）
- [ ] 明らかに不正解と分かる選択肢がないか

### 解説

- [ ] なぜ正解なのかを説明しているか
- [ ] なぜ他が不正解なのかに触れているか（理想）
- [ ] 「へぇ」と思える追加情報があるか
- [ ] 出典が明記されているか

### 全体バランス（定期レビュー時）

- [ ] テーマ別比率は推奨範囲内か
- [ ] 難易度別比率は推奨範囲内か
- [ ] 出題パターンが偏っていないか
- [ ] 認知レベルが「記憶」に偏りすぎていないか
