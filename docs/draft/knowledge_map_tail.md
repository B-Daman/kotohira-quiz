### 主要課題と方針

**1. 基礎知識問題（定義型）の質の改善**
- 固有名詞当てではなく、**概念・仕組みを問う問題**を追加
- 例: 「石段かごとは何か」「流し樽とは何か」「金毘羅講とは何か」
- 知的好奇心を刺激し、琴平を深く理解するための入口

**2. 理由型問題の大幅拡充（12問 → 40問以上）**
- 「なぜ」を問うことで背景・因果関係の理解を促す
- 「へぇ」感が最も高い出題パターン（情報ギャップ理論）

**3. easy問題の追加（50-90問）**
- 観光客が楽しめる基礎問題が不足
- 序盤にeasyを配置 → 自信 → 中盤medium → 終盤hard（離脱率最低の配置）

**4. 比較型・エピソード型の新設**
- 「AとBの違いは?」「○○が△△した際のエピソードは?」
- 知識の構造化と物語性を両立

### 問題作成の指針

1. 新テーマは **定義型 → 理由型 → 特徴型 → 事実想起** の順で作成
2. 時期型・数量型は既に十分なので意識的に抑える
3. 1テーマにつき複数パターンで問い、学習効果を高める
4. easy問題を意識的に増やす（観光客向けの入口）
5. 解説はSEEEDフレームワーク（Source/Essence/Episode/Expansion/Discovery）で質を高める
6. ディストラクターは「よくある誤解」に基づき、正解と同カテゴリ・同粒度にする
