# リサーチメモ: 琴平町関連情報（2026-04-06取得）

## 琴平町電子地域通貨KOTOCA
出典: https://www.town.kotohira.kagawa.jp/site/denshitiikituuka-kotoca/

### 事実リスト
- 正式名称は「琴平町電子地域通貨KOTOCA（コトカ）」
- 町内の加盟店舗で利用可能な町内限定の電子マネー
- 1コトカ＝1円
- カード型とアプリ型の2種類がある
- 琴平町民だけでなく町外の方もアプリダウンロードで利用可能
- チャージは1,000円単位
- チャージしたマネーに有効期限はなし
- プレミアムポイント：チャージ金額の2%が付与される（例：10,000円チャージで200ポイント）
- 1ポイント＝1円として加盟店で利用可能
- ポイント有効期限：最終利用日から180日間
- 町からの補助金などがマネーに付与される場合あり
- 担当課：企画防災課 企画担当（Tel 0877-75-6711、Fax 0877-73-2120）
- ページ更新日：2023年1月6日

### 既存問題との重複メモ
- KOTOCAについては既存問題なし（全て新規情報）

## こんぴら石段マラソン
出典: https://www.town.kotohira.kagawa.jp/soshiki/8/10937.html（404のため、moshicom.com/111190 および sportsentry.ne.jp/event/t/16122 等から補完）

### 事実リスト
- 正式名称：こんぴら石段マラソン
- 2024年は第57回大会（2024年10月6日開催予定 → 第57回は悪天候で中止）
- 金刀比羅宮例大祭奉祝奉賛行事として開催
- 目的：観光地琴平の認識を深め、健脚を祈願すること
- コース：表参道から金刀比羅宮御本宮までの785段を往復
- コース距離：約2.5km
- 標高差（高低差）：約170m
- 定員：785名（参加者多数の場合は抽選）
- 速さや到着順位を競う大会ではない
- 主催：金刀比羅宮例大祭奉祝奉賛会、琴平町
- 会場：金陵の郷 くすのき広場（香川県仲多度郡琴平町623番地）
- コース：金陵の郷 → 金刀比羅宮 御本宮・三穂津姫社参拝（折返し） → 金陵の郷
- 開会式：9時30分～、スタート：10時00分
- 受付時間：8時30分～9時30分
- 制限時間：正午までにゴール
- 参加資格：健康で完歩する自信がある人
- 参加費：2,000円／1名（2024年大会。過去には無料や1,000円の時期もあり）
- 参加賞：記念Tシャツ、うどん・ソフトクリーム等割引券（2024年大会）
- 過去の参加賞実績：金刀比羅宮お守り、メダル（第43回大会・2008年）
- 種目区分（第43回大会の例）：
  - 6km：男子（高校生～39歳）10:00スタート
  - 4km：男子40代（10:03）、男子50代（10:06）、男子60歳以上（10:06）、女子高校生以上（10:09）、中学生男女（10:09）
- 前回（第42回）参加者：555人

## 鞘橋（さやばし）
出典: https://online.bunka.go.jp/heritages/detail/185280

### 事実リスト
- 正式名称：鞘橋（さやばし）
- 文化財区分：登録有形文化財（建造物）
- 時代区分：近代その他／明治
- 所在地：香川県仲多度郡琴平町阿波町
- 明治2年（1869年）に改築
- 明治38年（1905年）に現在地に移築
- 改築により橋桁を用いない両岸から組み出す形式に変更
- 構造：木造反橋（屋根付き）
- 長さ：23.6メートル
- 幅：4.5メートル
- 屋根材：銅板葺
- 数量：1基
- 金刀比羅宮の祭儀実施時のみ使用される神橋
- 登録年月日：1998年（平成10年）4月21日
- 所有者：宗教法人金刀比羅宮
