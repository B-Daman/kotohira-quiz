## 4. 学習効果を高める工夫

### 4.1 解説（explanation）の効果的な書き方

ご当地検定やクイズアプリの成功事例から抽出した、解説の5つの要素。

#### SEEED フレームワーク（解説の5要素）

| 要素 | 説明 | 例 |
|------|------|---|
| **S**ource（出典） | 信頼できる情報源への参照 | 「（出典: 金刀比羅宮公式サイト）」 |
| **E**ssence（本質） | 正答とその核心的な理由 | 「本宮までの石段は785段です。」 |
| **E**pisode（エピソード） | 記憶に残るストーリー | 「この段数は1817年の改修で確定しました。」 |
| **E**xpansion（発展） | 関連知識への広がり | 「奥社まで含めると1,368段になります。」 |
| **D**iscovery（発見） | 「へえ」と思わせる豆知識 | 「なお、石段を寄進した人の名前が刻まれた段もあります。」 |

#### 解説の良い例・悪い例

**悪い例（事実の繰り返しだけ）:**
> 金刀比羅宮の通称は「こんぴらさん」です。

**良い例（SEEED要素を含む）:**
> 金刀比羅宮の通称は「こんぴらさん」です。この呼び名は、サンスクリット語の「クンビーラ（Kumbhīra）」が「金毘羅」と音写され、さらに親しみを込めて「こんぴらさん」と呼ばれるようになったものです。年間200〜300万人の参拝客がこの愛称で呼んでいます。（出典: 金刀比羅宮公式サイト）

### 4.2 「知りたくなる」問題の作り方

クイズアプリの成功事例から、エンゲージメントを高める問題設計の原則。

1. **意外性を問う**: 「当たり前」と思っていた知識を覆す問題
   - 例: 「参道の石段の途中で一段だけ下がる場所があるのはなぜ？」
2. **ストーリーを暗示する**: 問題文自体に物語の入口がある
   - 例: 「幕末の志士・高杉晋作を匿った琴平の人物は誰？」
3. **身体感覚に訴える**: 訪問時の体験と紐づく
   - 例: 「石段785段を登ると、標高約何メートルの地点に到達する？」
4. **比較で引き込む**: 他の有名なものとの対比
   - 例: 「現存する日本最古の芝居小屋はどれ？」
5. **数字のインパクト**: 驚きのある数値
   - 例: 「五人百姓の歴史は何年以上？」→ 700年以上

### 4.3 出題の順序・組み合わせの工夫

1. **難易度グラデーション**: 序盤は易しめ→中盤で応用→終盤で挑戦的な問題
   - 1問目から難問だと離脱率が上がる（クイズアプリ調査より）
2. **カテゴリの散らし**: 同一カテゴリが連続しないようシャッフル
3. **テーマ回遊**: 10問セットの中に最低3カテゴリを含める
4. **伏線回収**: 前の問題の解説が次の問題のヒントになる配置

### 4.4 リピート受験を促す仕組み

| 手法 | 解説 | 事例 |
|------|------|------|
| **公開テーマ制** | 毎月/毎季テーマを予告し、テーマ問題を出題 | 京都検定 |
| **時事問題枠** | 最近の出来事を一定割合で出題 | 東京シティガイド検定（36%） |
| **段位・称号** | 正答率に応じた称号付与 | 奈良ソムリエ |
| **問題プール拡大** | 継続的な問題追加で「飽き」を防止 | 琴平クイズ（現在882問） |
| **間違い直しモード** | 不正解問題を優先再出題 | ロードマップPhase 1.5「今日の復習」 |

### 5.6 ディストラクター（誤答選択肢）の品質向上

四択問題の学習効果は、正答だけでなく**誤答選択肢の質**に大きく依存する。

#### 良いディストラクターの条件

1. **もっともらしい**: 正答と同じカテゴリ・同じ粒度の選択肢
2. **学習につながる**: 誤答を選んだ理由から「なるほど、そっちではなく…」と学びがある
3. **ランダムでない**: 完全に無関係な選択肢は除外力を測れない

#### 例

- 良い例: 「金刀比羅宮の主祭神は？」→ A.大物主神 **B.大国主神** C.素戔嗚尊 D.天照大御神
  - 大国主神は大物主神と混同されやすく、学習効果が高い
- 悪い例: 「金刀比羅宮の主祭神は？」→ A.大物主神 B.織田信長 C.富士山 D.東京タワー

## 6. まとめ: 琴平クイズが目指すべき姿

### ご当地検定から学ぶ3つの成功要因

1. **体系的なカテゴリ設計**: 地域の全体像をカバーする10前後のカテゴリで、偏りのない知識体系を構築する
2. **段階的な難易度設計**: 誰でも楽しめる入口（easy）から、マニアが唸る奥行き（hard）まで、明確なグラデーションを持つ
3. **継続的な鮮度維持**: 時事問題・季節テーマ・問題プール拡大で「やり尽くした感」を防ぐ

### ご当地検定の課題から学ぶ教訓

- 「地域内の受験希望者が一通り合格すると、以後は受験者が集まりにくくなる」（Wikipedia「ご当地検定」）
- 対策: 問題の継続的追加、テーマローテーション、難易度コース分け、コミュニティ要素（ランキング・バッジ）

### 琴平クイズの差別化ポイント

琴平クイズは紙の検定試験ではなく**デジタルクイズアプリ**であるため、以下の優位性がある。

| 紙の検定試験 | 琴平クイズ（デジタル） |
|------------|---------------------|
| 年1〜2回の実施 | 毎日プレイ可能 |
| 固定の100問 | 882問以上からランダム出題 |
| 合否のみ | スコア・カテゴリ別正答率 |
| 事後の解説本 | 即時解説フィードバック |
| 個人受験 | コミュニティ機能（Phase 2以降） |

この優位性を活かし、**「琴平の知識が自然に身につく日常的なクイズ体験」**を目指すことが、ご当地検定との差別化であり琴平クイズの存在意義となる。
